# Design System

## Typography

- Headings: Cinzel via Google Fonts, `font-heading` and `font-serif`.
- Body: General Sans via FontShare, `font-sans`.
- Fallback: Plus Jakarta Sans, then `sans-serif`.

## Identity

| Token | Value | Use |
| --- | --- | --- |
| navy | #0c3a4a | Primary color, backgrounds, buttons |
| deepnavy | #0a2e3b | Header, footer, modals |
| teal | #125566 | Highlights, links, accents |
| teal-300 | #5eead4 | Hover states, active icons |
| teal-500 | #14b8a6 | Action buttons |
| lightgray | #f0f0f0 | Alternating backgrounds |
| slate | #f8fafc | Soft background |

## Interaction

The public registration form uses a numbered progress sequence with connecting lines. Completed steps use teal success states, the current step uses the primary teal action color, and inactive steps remain quiet and legible. The sequence is responsive and preserves labels at larger widths.
