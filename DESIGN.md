# BRM Design System

## Visual direction

Use one polished, institutional interface across administration, the member portal, and public forms. Preserve the BRM identity with petroleum blue, navy, glacial teal, and restrained warm-gold details. Use atmospheric gradients, soft illumination, and brief motion selectively to create depth and clarify active areas; avoid product-specific imitation, neon, sci-fi effects, decorative overload, and unnecessary motion.

## Typography

- Interface text: Plus Jakarta Sans with system sans-serif fallbacks.
- Administrative headings: the interface sans-serif, with restrained weight and tracking.
- Canonical and print documents may retain their dedicated serif typography.
- Use monospace only for codes, protocols, and data that benefit from fixed-width alignment.

## Identity tokens

| Token | Value | Use |
| --- | --- | --- |
| `--brm-navy` | `#113240` | Primary actions and strong text |
| `--brm-petroleum` | `#226380` | Links, focus, and selected states |
| `--brm-glacial` | `#A3C3C7` | Quiet highlights and dark-theme accents |
| `--brm-gold` | `#B58A55` | Small institutional details |
| `--brm-canvas` | `#F4F6F5` | Application background |
| `--brm-paper` | `#FFFFFF` | Content surfaces |
| `--brm-line` | `#DCE4E2` | Dividers and borders |

Dark mode uses charcoal-green surfaces and preserves the same contrast and accent roles.

## Components and interaction

- Keep surfaces, controls, and full-round badges on distinct, consistent corner radii.
- Use clear focus indicators, semantic status colors, concise feedback, and readable empty/error states.
- Keep navigation and forms touch-friendly and responsive; tables may scroll horizontally when necessary.
- Keep motion brief and subtle, and respect reduced-motion preferences.
- Preserve all routes, permissions, data flows, and canonical print layouts when changing presentation.

The public registration form keeps its existing numbered progress sequence and responsive labels.
